Diagram Builder

Each line becomes a box connected to the next. End a line with "?" to draw it as a decision diamond.

Use "-->" instead of "->" for a dashed reply arrow.

Each task starts when the previous one finishes. The number is its length in days.

Members ending in "()" are drawn as methods; the rest as fields.

"Parent <- Child" draws inheritance, "A -> B" an arrow, "A - B" a plain link.

The trigger label after ":" is optional. The first state gets the start marker automatically.

Mood scores: 1 = terrible, 5 = great.

Write "int id" to give a field a type; bare fields are typed "string".

Use one-to-one, one-to-many, many-to-one or many-to-many (or 1-1, 1-n, n-1, n-n). The label after ":" is optional.

Separate multiple events in one period with semicolons.

Each indented line branches off the line above it.
